# 領収書の写真 → 立替経費の ZIP（番号つきの写真＋CSV）

社内アプリの「立替経費をまとめて登録」に入れる ZIP を作る。写真には `R001_2026-10-05_1200.jpg` のような **番号つきの名前** を付け、CSV にも同じ名前を書く。アプリはこの名前で写真と明細を結びつけるので、元の写真の名前（スマホだと全部 `image.jpg` のこともある）に左右されない。

## 手順

### 1. 写真の一覧を作る

- 渡された写真（JPG・PNG・HEIC・PDF）の **実際のファイルのパス** を一覧にする。
  - Claude.ai では `/mnt/user-data/uploads/` などにある。`ls` で確認する。
  - Claude Code などでフォルダを指定された場合は、そのフォルダの中（サブフォルダは見ない）。
- ファイル名の順（名前の昇順。同じ名前が並ぶならアップロード順）に処理する。
- 写真がファイルとして見つからない（チャットに貼られた画像しかない）場合は、ZIP を作れない。CSV だけを作り、最後に「写真をファイルとして添付し直すと、番号つきの ZIP にできます」と伝える（→ 手順5）。

### 2. 1枚ずつ読む

写真を1枚ずつ見て読み取る。読み取りは自分の目（画像の内容）で行い、外部の OCR サービスには送らない。

| 項目 | 書き方 |
|---|---|
| date（日付） | 領収書の発行日・利用日。`YYYY-MM-DD`（例: `2026-10-05`）。和暦は西暦にする（令和8年 = 2026年） |
| amount（金額） | **実際に支払った税込の合計**。整数（`¥`・`,`・`円` は付けない）。お釣り・お預り・ポイント利用前の金額と間違えない |
| vendor（支払先） | 店名・会社名（例: `日本交通`、`スターバックス 渋谷店`）。分からなければ空 |
| purpose（用途） | 何の費用か。但し書き・品目から「交通費（タクシー）」「会議費（カフェ）」「書籍代」のように短く。写真から分からないこと（同行者・案件名など）は書かない |
| note（メモ） | 読み取りに自信がないところ、手書き、かすれ、金額の候補が複数ある、など。問題なければ空 |

- 1枚の写真に領収書が2枚以上写っていたら、**同じ src で行を分ける**（番号は R003、R003-2 のように枝番になり、写真は1枚だけ入る）。
- 領収書ではない写真（風景・名刺など）は行を作らず、最後に「領収書ではないので除外した写真」として伝える。
- 数字が読めないときは、その欄を空にしてメモに「金額が読めない」などと書く（推測で埋めない）。
- クレジットカードの控えと領収書が両方ある場合は、領収書のほうを使い、二重に数えない。

### 3. ZIP を作る（同梱のスクリプトを使う）

読み取った内容を `rows.json` に書き、`scripts/package.py` を実行する。番号の振り方・ファイル名・CSV の形式はスクリプトがそろえるので、自分で ZIP を組み立てない。

```json
[
  {"src": "/mnt/user-data/uploads/IMG_1234.HEIC", "date": "2026-10-05", "amount": 1200, "vendor": "日本交通", "purpose": "交通費（タクシー）", "note": ""},
  {"src": "/mnt/user-data/uploads/IMG_1235.jpg", "date": "2026-10-09", "amount": 885, "vendor": "スターバックス 渋谷店", "purpose": "会議費（カフェ）", "note": ""}
]
```

```bash
python3 <このスキルのフォルダ>/scripts/package.py rows.json <出力フォルダ>
```

- 出力フォルダ: Claude.ai なら `/mnt/user-data/outputs/`、Claude Code なら写真と同じフォルダ。
- できるもの: `立替経費_YYYYMMDD.zip`。中身は CSV（`番号,ファイル名,日付,金額,支払先,用途,元のファイル名,メモ`）と、番号つきの名前にコピーした写真。**元の写真は変えない**。

### 4. 結果を伝える

- 表で一覧を見せる（番号・日付・金額・支払先・用途・元のファイル名）。最後に件数と合計金額。
- メモ欄に何か書いた行は「確認してほしい行」として、理由と一緒に箇条書きにする。
- ZIP をダウンロードできるように渡し、次の手順を伝える:
  1. アプリの「社内請求・経費」→「＋ 立替経費をまとめて登録（CSV＋写真）」を開く
  2. この ZIP を1つ、そのまま枠に入れる（展開しなくてよい）
  3. 写真が番号で自動的に結びつくので、内容を確認して「登録」を押す

### 5. 写真がファイルとして無いとき（CSV だけ）

ZIP は作らず、同じ見出しの CSV だけを作る（`ファイル名` と `元のファイル名` は空）。アプリでは CSV を入れたあと、各行で写真を選んで結びつける。

## してはいけないこと

- 元の写真を書き換える・名前を変える（コピーにだけ番号を付ける）
- 金額を税抜にする、端数を丸める（領収書の原本と1円単位で一致しないと、アプリで提出できない）
- 写真に写っていない情報（同行者名・案件名など）を用途に書き足す
